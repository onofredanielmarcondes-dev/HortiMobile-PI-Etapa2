# HortiMobile Pro - Prova de Conceito (PoC)

Este repositório contém a Prova de Conceito (PoC) desenvolvida para a Etapa 2 do Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas (ADS).

## 🚀 Funcionalidade Validada
Foi validada a integração completa entre a interface (Frontend) e o Banco de Dados (Backend), permitindo a listagem dinâmica de produtos de hortifrúti, cadastro em tempo real através do formulário e a baixa automática do estoque crítico.

## 🛠️ Tecnologias e Ambiente Utilizados
- **Servidor Local:** UwAmp (Apache + MySQL)
- **Linguagem:** PHP (utilizando a extensão PDO)
- **Banco de Dados:** MySQL (Gerenciado via phpMyAdmin)
- **Editor de Código:** VS Code

## 📦 Como Rodar o Projeto Localmente
1. Mova os arquivos do projeto para o diretório `www` do seu servidor UwAmp.
2. Importe o arquivo `hortimobile.sql` no seu phpMyAdmin para recriar o banco de dados.
3. Verifique se as credenciais no arquivo `conexao.php` estão configuradas com o usuário `root` e senha `root`.
4. Acesse no seu navegador: `http://localhost/HortiMobile-PI-Etapa2/`
